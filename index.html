1. The Machine: Agentic Pipelines & Evals, Not a Content Calendar Systems

  • Agentic Daily Tooling: Daily workflows run through Claude Code, MCP servers, and custom agent skills to turn raw system logs and telemetry into structured drafts without human blocking.

2. The Extraction: Sourcing Truth from the Support Trenches Zero Hand-Holding

The hardest part of technical content isn't generating words; it's extracting tacit truth from engineers who have other jobs. To bypass generic marketing questionnaires:

  • I voluntarily took over support ticket triage for our entire infrastructure monitoring team.
  • I sat inside high-stakes enterprise escalations with CTOs, Cloud Architects, and DevOps leads to diagnose exactly where distributed systems collapsed.
  • I interviewed the core platform developers on the fix, bypassing PR filters to turn undocumented production edge cases into high-credibility architecture guides.

The parallel to modern data: Just like silent memory leaks crash production servers, silent schema drift and corrupted upstream inputs break modern data warehouses (Snowflake, BigQuery, dbt). I write from the incident log, not the brochure.

3. Taste & Anti-Slop: Why Naive LLM Drafts Fail Technical Audiences Judgment

A model given a generic prompt writes a Wikipedia summary disguised as a blog post. It outputs polite abstractions ("Chaos engineering tests resilience in turbulent conditions"). Practitioners smell AI and bounce immediately.

My bar for content: does this sound like someone who debugged this pipeline at 2 AM? Concrete failure modes, verified CLI outputs, and multi-step prompt chains with programmatic schema validation keep the output sharp, credible, and authentic.
